# Сатурн — прототип 7: подарок от суммы

Публичный адрес GitHub Pages: https://kate854.github.io/7/ . Исходники — ветка `main`; автономная сборка для публикации — `gh-pages`.

## Запуск и скачивание

```sh
npm install
npm run dev
```

- `npm test` — 12 тестов бизнес-логики.
- `npm run build` — проверка TypeScript и сборка единственного автономного HTML.
- `npm run preview` — запуск production-сборки.
- `prototype.html` — готовый файл для скачивания и открытия двойным щелчком. Все стили, React, логика и SVG встроены. Интернет и сервер не нужны.
- `docs/index.html` — идентичная копия для публикации.

После изменений пересоберите приложение, обновите `prototype.html` и `docs/index.html`, а затем также файл `index.html` ветки `gh-pages`.

## Сценарий новых макетов

В начальной корзине акционный товар за 555 ₽. До подарка не хватает 445 ₽. По новым макетам в поп-апе **пять** вариантов: 444, 700, 578, 624 и 662 ₽. Ограничение из прототипа 6 на четыре варианта здесь не применяется.

Добавление товара включает счётчик. При 555 + 444 = 999 ₽ подтверждение недоступно. Увеличение до двух единиц даёт 1443 ₽. Товар за 700 ₽ даёт 1255 ₽. При достижении 1000 ₽ включительно появляется сообщение **«Вы получаете подарок!»** и активируется подтверждение. Черновик не меняет корзину до подтверждения.

Один фиксированный бесплатный подарок — герметик Vetonit Comfort Sil, серый 06, 280 мл. При 2000, 3000 ₽ и более подарок по-прежнему один. Падение суммы ниже порога удаляет подарок; восстановление суммы возвращает его. Все пять вариантов поп-апа и начальный товар участвуют в акции, остальные товары — нет.

Отмена, крестик, Escape и клик по фону сбрасывают черновик. Повторное открытие начинает выбор заново. Реализованы ограничение фокуса внутри диалога, возврат фокуса, запрет фоновой прокрутки и прокрутка содержимого на небольшом экране.

Работают поиск по названию/артикулу, выбор товаров, счётчики, удаление, избранное, переключатель покупателя и очистка с подтверждением. Второстепенные действия демонстрационные. Backend не используется.

## Проверка

12 unit-тестов: состав каталога, пороги 999 и 1000, сумма с количеством, изоляция черновика, объединение без дублей, подарок только один, исключение неакционных товаров и корректные суммы выбранных позиций.

В Chromium проверены все состояния, пять вариантов поп-апа, добавление за 700 и 662 ₽, сценарий 999 → 1443, один подарок при 3000+, потеря/восстановление права, четыре способа закрытия, сброс выбора, фокус, блокировка фона и мобильная прокрутка. Автономная сборка не запрашивает отдельных изображений, JS или CSS.

## Визуальные данные

Упаковки и знак логотипа воссозданы SVG-иллюстрациями; оригинальные фотографии отдельно не предоставлены. В макетах итог 10 725 ₽ не совпадает с суммой отдельных строк. Как в предыдущем прототипе, для динамических итогов используются суммы реальных цен строк, а не противоречащий им статический итог. Четвёртая неакционная позиция Granit Fix за 967 ₽ взята из финального макета. Скидка, услуги и бонусы вне акции — демонстрационные значения макета, новая формула для них не вводилась.
